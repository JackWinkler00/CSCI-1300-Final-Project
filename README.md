# CSCI 1300 Final Project

## Theme

This game is about bringing the One Ring to Mordor to destroy it. The player will travel with the fellowship to complete this task, though it may be perilous. Along the way, the player will interact with many of the characters familiar in this realm as well as managing the Hobbits' rations and deciding whether or not to resist or embrace the influence of the All Seeing Eye. This game is built around JRR Tolkien's Middle Earth and his trilogy, The Lord of the Rings.
